02

SchemaDrift

Catch the risky migration before it ships.

Paste two versions of a database schema, SQL or JSON, and SchemaDrift lists every change and marks it breaking, review or safe. Dropped columns, NOT NULL traps, narrowed types, new unique constraints.

schemadrift - sample
BREAKING  users.phone      dropped
BREAKING  orders.note      NOT NULL added
REVIEW    users.name       VARCHAR(100)→(50)
SAFE      orders.coupon    column added

There is a small JSON API so it can run as a CI check, and the diff logic is covered by 27 tests.

03

Campus Connect

One place for courses and materials.

A department platform with three roles: student, lecturer and admin. Lecturers create courses and upload learning materials. Students enroll and open what they need.

JWT auth with bcrypt, file uploads, server-rendered pages with Next.js, and an Express and MongoDB backend. I also added an AI course assistant: students ask questions about the uploaded PDFs and DOCX files and get answers with source citations (embeddings and retrieval with Gemini), and each material can generate a summary and a short quiz.
